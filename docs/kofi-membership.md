# Forest Guardian payment access

Set the Forest Guardian tier to **USD $5 per month** in Ko-fi. In the backend environment, set `KOFI_VERIFICATION_TOKEN` to the private verification token shown on Ko-fi's [Webhooks page](https://ko-fi.com/manage/webhooks), then set that page's webhook URL to `https://www.kella.online/api/webhooks/kofi`. Keep the token in the backend environment only. Google sign-in must also be configured for automatic approval.

Ko-fi sends a form-encoded `data` field containing payment JSON. The backend verifies the token and records each qualifying payment once by both message ID and transaction ID. Only a `Subscription` event with `is_subscription_payment: true`, the exact Forest Guardian tier, USD currency, and an amount of at least `$5.00` qualifies. The Ko-fi payer email must exactly match the verified Google account email after trimming and case normalization. If payment arrives before signup, the record is applied when that Google account signs up.

Each qualifying payment covers one calendar month from its Ko-fi payment timestamp. A renewal sets the paid-through date from that renewal's timestamp; replayed deliveries do not extend access. Backend authentication checks this date on every request, including existing sessions. A changed Google email must match a qualifying payment at the new email. Ko-fi currently sends [payment webhooks only](https://help.ko-fi.com/hc/en-us/articles/360004162298-Does-Ko-fi-have-an-API-or-webhook), so access expires by the paid-through date rather than by a cancellation event. A late renewal restores access when its payment arrives.

An admin can approve or terminate a Google signup in Kingdom Members. Manual approval remains valid without a qualifying Ko-fi payment, including for existing members whose earlier `$2` subscription continues at its original price. A manual termination is never reversed by a payment webhook. Ko-fi says [changing a tier price affects new subscribers only](https://help.ko-fi.com/hc/en-us/articles/4402945994001-Ko-fi-Memberships-and-Membership-Tiers).

# Forest Guardian VIP access

Set the Forest Guardian tier to **USD $5 per month** in Ko-fi. In the backend environment, set `KOFI_VERIFICATION_TOKEN` to the private verification token shown on Ko-fi's [Webhooks page](https://ko-fi.com/manage/webhooks), then set that page's webhook URL to `https://www.kella.online/api/webhooks/kofi`. Keep the token in the backend environment only. Google sign-in enables automatic matching to verified account emails; other login methods can be matched by an admin to a verified payment.

Ko-fi sends a form-encoded `data` field containing payment JSON. The backend verifies the token and records each qualifying payment once by both message ID and transaction ID. Only a `Subscription` event with `is_subscription_payment: true`, the exact Forest Guardian tier, USD currency, and an amount of at least `$5.00` qualifies. The Ko-fi payer email must exactly match the verified Google account email after trimming and case normalization. If payment arrives before signup, the record is applied when that Google account signs up.

Each qualifying payment covers one calendar month from its Ko-fi payment timestamp. A renewal sets the paid-through date from that renewal's timestamp; replayed deliveries do not extend access. Backend authentication recomputes VIP access from the database on every request, including existing sessions. Once verified, the Ko-fi payment email remains bound to that account and renewals follow that binding. Ko-fi currently sends [payment webhooks only](https://help.ko-fi.com/hc/en-us/articles/360004162298-Does-Ko-fi-have-an-API-or-webhook), so VIP access expires by the paid-through date rather than by a cancellation event. An approved account then retains regular access. A late renewal restores VIP access when its payment arrives.

Signup opens the payment page with Ko-fi's official embedded checkout. In Ko-fi Payment Settings, enable **Default to memberships** so the Forest Guardian tier appears first. Kella permits the Ko-fi frame only on this page. The page checks `/api/auth/kofi/status` using an authenticated session or limited payment identity cookie. The limited cookie cannot access member APIs. Once approved, an unpaid account can choose regular access through `/api/auth/kofi/regular`; active VIP accounts enter the base. Existing regular members can upgrade from the Guardian preview without signing up again.

Approved regular accounts can read **Members** and **Calendar**. Personal tools, attendance responses, research, training, healing, profile editing, and the base require Guardian VIP. Pending or terminated accounts cannot enter member pages. Owner/admin access and explicitly granted private member access are preserved. Public homepage, policies, selected champions, and migration submissions remain available; management and migration exports stay admin-only. VIP does not grant admin privileges.

Manual approval grants regular access and does not fabricate a payment. Google payments matching the verified email can approve automatically. Other users submit their payer email and optional receipt reference for admin review in **Kingdom Members**; these details alone do not prove ownership. An admin must match an unclaimed, verified webhook payment to the applicant. A membership can be bound to only one account.

A manual termination is never reversed by a payment webhook. Ko-fi says [changing a tier price affects new subscribers only](https://help.ko-fi.com/hc/en-us/articles/4402945994001-Ko-fi-Memberships-and-Membership-Tiers); an old `$2` payment does not meet this site's `$5` access requirement.
